# Ideas to 1

Prototype of revazkuparadze.com: "Ideas to life". Idea planes you can drag, throw and open; a public Idea Note board; About and Craft pages.

It's a single static page: open `index.html`, or view it on GitHub Pages.

Note: the shared idea board saves notes only when the page runs as a claude.ai artifact. On GitHub Pages, a sent idea flies for the visitor but isn't stored.
